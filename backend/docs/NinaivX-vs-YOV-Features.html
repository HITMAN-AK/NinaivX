NinaivX vs You, Only Virtual (YOV) — Feature Comparison

Ashwin Kumar Ramesh Kumar · MSc Artificial Intelligence, University of Sheffield

This comparison is based on YOV's public materials (company website myyov.com, press releases, news coverage, and the BBC documentary AI Confidential with Hannah Fry, 2026), verified June 2026. Where YOV does not publicly document a feature, it is marked “not documented” rather than “absent”, because absence of documentation is not proof of absence.

B. Features NinaivX has that YOV lacks or does not document

FeatureYOVNinaivXNote
Living companion mode for loneliness (a friend, not grief)✗✓YOV's scope is the deceased / legacy use case only; it markets no general companion.
Air-gapped safety mode (deceased persona cut off from the internet)?✓NinaivX enforces this in code (the deceased agent has no tools); YOV does not document such a mechanism.
Web-connected mode for current information✗✓The NinaivX companion can search the live web; YOV has no companion mode.
Anti-fabrication grounding (persona limited to stored personality + memory)?◑Reduces invented “memories”; basic in NinaivX, not documented by YOV.
AI-transparency disclosure to the user?✓NinaivX implements this: the persona honestly confirms it is an AI if asked, and a disclosure notice is provided via the API for onboarding + an in-app indicator. YOV is designed to feel like the real person, with no documented disclosure.
Open, documented, reproducible architecture✗✓YOV is “fully patented”, proprietary and closed; NinaivX is an open research artefact.
Non-commercial (free research prototype)✗✓YOV is paid (~$499 setup + ~$39.99/month).
Privacy / data-sovereignty stance (UK / GDPR)?◑NinaivX is designed privacy-first (UK intent); YOV is US-based (Azure/Google Cloud) with no documented UK/GDPR stance.
Underlying philosophy (the deepest difference). YOV's founder treats “grief and death itself as a problem to be solved” — the goal is to keep talking to the person. NinaivX takes the opposite, evidence-informed stance: it is a grief-support and closure tool that aims to help people mourn healthily, not a permanent replacement. This directly engages the ethical debate raised in the BBC documentary — whether grief is a necessary human process.
Key takeaway for the viva: “YOV and NinaivX share the core voice features, so I don't claim to be first. What YOV does not offer or document is a safety design that stops the AI fabricating things the real person never said, transparency that it's an AI, an open architecture, and a companion mode — and, unlike a closed commercial product, I evaluate whether my safety measures actually work.”
