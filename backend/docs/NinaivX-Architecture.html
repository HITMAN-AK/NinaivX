Key design decisions

  • Agent, not a fixed script: the AI decides whether to use a tool (web) — the deceased persona is denied that ability in code.
  • Privacy by architecture: air-gap is enforced by not binding tools, not by a prompt request.
  • Memory = rolling summary, not full transcripts — small + fast.

Performance & safety

  • Low latency: memory rewrite runs as a background task after the reply is sent.
  • Secure: every request needs a valid Supabase JWT; personas are owner-scoped.
  • Resilient: app boots even if a provider key is missing (clean 503).
  • Transparent: persona never denies being an AI; honest if asked, plus a public disclosure notice.

Two request flows

  • Text chat: /api/chat → agent → reply (JSON).
  • Voice "phone call": audio → STT → agent → TTS → audio, in the persona's cloned voice.
  • Same brain serves both.
